# Offline final narrative evidence

Helper: `/tmp/ld-final-analysis.py`. It reads only a completed immutable primary
archive. It never opens a live run directory or writes source/site/archive data.
It executes the exact verifier stored under the archive's operational directory
from already-hash-checked source bytes, without reading or writing bytecode caches,
checks that verifier against the manifest, and performs mandatory offline archive
verification/replay before summarizing. Its SQLite reads are temporary decompressed
archived copies. No API calls, new clustering, downloads or builds occur.

After the final main archive is installed and verified complete:

```sh
python3 /tmp/ld-final-analysis.py \
  --archive /mnt/disks/data/ld-clustering/experiments/2026-10-20-main-v2-seed42 \
  --binary /tmp/ld-clustering-v2-frozen
```

Default output is a compact Markdown table and explanatory facts. For full JSON,
including active cluster definitions and dataset-label distributions:

```sh
python3 /tmp/ld-final-analysis.py \
  --archive /mnt/disks/data/ld-clustering/experiments/2026-10-20-main-v2-seed42 \
  --binary /tmp/ld-clustering-v2-frozen \
  --format json
```

The helper emits known planning and assignment/reassignment dollars and fractions,
active/nonempty cluster counts, named/Other coverage, accepted refusal requests vs
persisted events and distinct refused points, final named/Other status of those
points, committed reviews/empty reviews and create/rename/merge/split/retire counts,
reassignment events (which can retain membership), unknown-usage physical row indices, pair confusions and
agreement, guarded total-cost/time ratios and interpretation caveats. Fractions
use the known recorded subtotal; unknown charges can change full-cost fractions.
Repeated refusal requests do not imply multiple distinct refused points. A later
review can assign a previously refused point. The post-hoc fixed-catalog control
is excluded from every primary total here.

It refuses interrupted archives, missing or altered payloads, a verifier different
from the archived bytes, wrong measured executable, mismatched counts/cost sums,
invalid membership/events or inconsistent metrics. Cost ratios require both
cost_complete flags. Time ratios require two complete uninterrupted loops.
One-order case-study scope, independent manager variation, evaluation-label limits,
Other singleton policy and illustrative-vs-observed maintenance are explicit.
